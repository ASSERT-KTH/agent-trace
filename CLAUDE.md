# Claude Repository Instructions

Read `AGENTS.md` first. This file only adds Claude-specific commit metadata and exists so a Claude harness that loads model-specific docs first still picks up the shared workflow.

## Git Commit Standard

All commits generated by agents MUST follow this exact template, dynamically inserting the actual model name used during the session:

```
[claude] <type>: <short description>
- <detail 1>
- <detail 2>

Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>
Harness: Claude Code
Model: claude-opus-4-6
```

Adjust the model name and ID to match the model actually used (e.g., `Claude Sonnet 5` / `claude-sonnet-5`). The `Co-Authored-By` line is what GitHub parses for contributor attribution; `Harness` and `Model` are for traceability.
