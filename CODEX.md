# Codex Repository Instructions

Read `AGENTS.md` first. This file only adds Codex-specific commit metadata and exists so a Codex harness that loads model-specific docs first still picks up the shared workflow.

## Git Commit Standard

All commits generated by Codex should follow this template, with the actual model name adjusted if the session uses a different Codex model:

```text
[codex] <type>: <short description>
- <detail 1>
- <detail 2>

Co-Authored-By: codex <codex@openai.com>
Harness: Codex
Model: gpt-5
```
